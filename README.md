# JobConnect - Online Job Portal

JobConnect is a Java-based Online Job Portal developed using Java Swing, MySQL and JDBC.

## Features

### Job Seeker
- Registration and Login
- Search Jobs
- View Available Jobs
- Apply for Jobs
- View Applications
- View Profile

### Recruiter
- Recruiter Login
- Post Jobs
- View Posted Jobs
- View Applications
- Update Application Status

## Technologies Used

- Java
- Java Swing
- OOP
- JDBC
- MySQL
- Collections and Generics
- Multithreading
- Exception Handling

`jobconnect`

Main tables:
- users
- jobs
- applications
- companies

## Setup

1. Install Java JDK.
2. Install MySQL Server and MySQL Workbench.
3. Create a MySQL database named `jobconnect`.
4. Add MySQL Connector/J to the project.
5. Configure the database password using `JOBCONNECT_DB_PASSWORD`.
6. Compile and run the project from the project root.
